# gh-webapp

## Суть
Лёгкий шаблон веб-приложения со встраиваемым YouTube-плеером: видео грузится лениво (по клику подставляется iframe с autoplay), есть чек-лист настройки под конкретный кейс. Заготовка для быстрого запуска страницы с видео.

## Стек
- **Vanilla JS** + HTML + CSS (без сборки и зависимостей).

## Архитектура
- `index.html` — разметка страницы/плеера.
- `main.js` — ленивое встраивание YouTube (`labnolIframe`: создание iframe по `data-id` с autoplay и нужными `allow`).
- `style.css` — стили; `readme.md` — чек-лист доработок (verification, заголовок, ускорение загрузки).

## Фичи
- **Ленивая загрузка YouTube:** iframe создаётся только по взаимодействию — быстрее первый рендер.
- **Настраиваемость:** видео задаётся через `data-id`; чек-лист обязательных/опциональных доработок.

## Сложные места
- **Производительное встраивание видео.** Отложенная подстановка iframe вместо тяжёлого раннего эмбеда — приём для ускорения загрузки и улучшения метрик.
- **Минимализм без зависимостей.** Чистый JS/HTML/CSS — переносимый шаблон под любой хост.

## Кейсы
- **«Быстрый YouTube-эмбед без лагов».** Ленивая подстановка iframe по клику как оптимизация.
- **Статус: до ИИ.**
- *Примечание: шаблон-заготовка с чек-листом доработок.*
